# Режим редактирования

Кнопка **✏️** в шапке. Без неё схема «только чтение»: смотри, выделяй, строй трассы. С ней — стройка.

## Что открывается на схеме

- **Кабели**: клик по свободному порту → красное кольцо, зелёные цели → второй клик → тип кабеля → готово.
- **Меню связи** на занятых портах: удалить или пересоединить кабель.
- **«+ добавить фидер»** прямо на карточке щита.
- **Модель-бар на ноде**: сменить модель устройства не заходя в детали — порты приведутся к новой модели (по номерам, занятые сохраняются).
- **Сдвиг номеров портов** («Порты» на ноде): свободным портам категории задаётся новая нумерация — удобно после переезда патч-корда.

## Что открывается на стойках

Клик по свободным юнитам собирает **диапазон** (зелёная подсветка), «Занять место?» → «Да» → создание устройства на эти юниты. Подробнее — тема «Стойки».

## Предохранители

- Пока открыт выбор модели или сдвиг номеров — новые связи не создаются (чтобы клик по порту не «строил кабель» случайно).
- Занятые порты при применении модели не переименовываются в конфликт и не меняют тип — только предупреждение.
- Удаление кабеля не трогает порты и IP.

Выключи ✏️ — и схема снова безопасна для «просто посмотреть».
