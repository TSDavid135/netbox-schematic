# Шапка страницы

Слева направо:

- **NetBox** (логотип) — вернуться в сам NetBox.
- **Поиск** — устройства и стойки по имени; выбор прыгает к объекту на схеме.
- **Обновить** — перечитать данные из NetBox (плагин не опрашивает сервер сам — жми после правок в другой вкладке).
- **Импорт / Экспорт / Аудит** — работа с Excel (отдельная тема «Импорт / Экспорт»).
- **Каталог** — модели устройств; ⚠ на кнопке = есть модели без портов.
- **Слои** — Питание, Console, VLAN, Wi-Fi, Circuits: подсветка связей выбранного слоя.
- **Фильтр ролей** — скрыть на схеме лишние роли.
- **Физический / Беспроводной** — переключатель вида портов.
- **✏️ Режим редактирования** — стройка (тема «Режим редактирования»).
- **Тема** — светлая/тёмная.
- **Имя пользователя** — меню профиля.

## Внизу справа

Бейдж версии **vX.Y.Z** — эта самая кнопка: «Последние изменения» и «Обучение».

## Панель схемы

Под шапкой у канваса свои настройки: стиль проводов (плавные/угловые, поверх портов), плотность нод, легенда типов портов. Они запоминаются в браузере.
