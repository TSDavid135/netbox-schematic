# Детали

Панель справа — «паспорт» того, по чему кликнул. Она глубже тултипа: тултип отвечает «что это», детали — «что с этим можно сделать».

## Устройство

Клик по **имени** на ноде (или в дереве, или на виде стоек): модель, роль, место, серийник, все порты с занятостью, IP-адреса, стек. Отсюда — правка полей (карандаш), назначение IP, «+ порт». Подробнее — тема «Характеристики устройства».

## Силовой щит

Клик по имени щита: список фидеров с параметрами (вольты/амперы/фазность), переименование, «+ фидер». Клик по фидеру подсвечивает его маршрут.

## Поведение панели

- Открытие деталей закрывает висящие тултипы — экран не захламляется.
- При правке полей позиция скролла сохраняется; при закрытии панели — сбрасывается.
- Закрыть: крестик или клик по фону схемы.

## На телефоне

Детали выезжают снизу почти на весь экран. Тултипы у портов появляются рядом с портом; блоки действий (выбор модели, сдвиг номеров портов) — по центру экрана.
