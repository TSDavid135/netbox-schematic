# Характеристики устройства

Клик по **имени устройства** (на ноде, в дереве или на виде стоек) открывает справа панель деталей — паспорт устройства.

## Что в паспорте

- Шапка: имя, модель, роль, стойка и юнит, статус, серийник.
- **Порты** — все, по видам, с занятостью: у занятого видно, куда идёт кабель; клик по строке подсвечивает связь на схеме.
- **IP-адреса** на интерфейсах — зелёные чипы. Кнопка «+ адрес» назначает IP прямо здесь (или на ноде во Беспроводном/сетевом виде).
- **Стек**: если это коммутатор — можно собрать VirtualChassis: выбери участников, задай позиции, один станет мастером. Имена участников должны отличаться (NetBox требует уникальность в пределах площадки).

## Правка (карандаш в шапке паспорта)

Открывает полную форму: имя, статус, роль, модель, платформа, площадка / серверная / стойка / юнит / сторона, серийник, описание. Так устройство переносится в другую стойку или юнит.

- Юнит — **одна** позиция (нижняя); сколько полок займёт устройство, решает **высота его модели** (Каталог → «Высота, U») — одинаковая у всех устройств модели.
- Смена модели здесь меняет только тип; чтобы привести порты к новой модели — Каталог → «По роли» или смена модели на самой ноде в режиме редактирования.

## Сценарий: назначить камере IP

1. Клик по имени камеры → детали.
2. В строке интерфейса «+ адрес» → введи `10.0.1.15/24`.
3. IP появится чипом и будет виден в тултипе порта на схеме.

## Сценарий: добавить нестандартный порт

Детали → «+ порт»: имя, вид (сетевой / патч-пара / ввод питания / розетка / консоль) и тип. Для разового порта это быстрее, чем менять модель.

При правке позиция скролла панели сохраняется — удобно менять несколько полей подряд.
