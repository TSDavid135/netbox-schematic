# Стойки

Вид стоек (вкладка над схемой) — физика: юниты, полки, кто где стоит.

## Чтение

- Стойка — рамка с нумерацией юнитов; устройства — плашки высотой в свои U (модель 2U — плашка в две полки).
- Длинные пустые диапазоны свёрнуты в «⇕ N» — наведи, чтобы узнать какие юниты; в режиме редактирования они раскрываются.
- Наведение на юнит показывает его номер и занятость; клик по устройству открывает его детали и подсвечивает ноду на схеме.

## Сценарий: поставить устройство в стойку

1. Включи ✏️ и кликни по свободному юниту — он подсветится зелёным (повторный клик — отмена).
2. «Занять место?» → **Да** → имя, модель, роль → «Создать».
3. Полок устройство займёт столько, какова **высота его модели** (в списке она видна: «Коммутатор (1U)», «Сервер (2U)») — юнит клика становится нижней полкой.

Высота — свойство **модели**, у всех её устройств она одинаковая; правится в каталоге («Высота, U»). Чтобы существующий девайс занял больше полок — подними высоту его модели там (NetBox откажет, если соседняя полка занята) или назначь ему модель нужной высоты (детали → карандаш → «Тип»).

## Сценарий: собрать стек прямо при создании

В окне создания устройства справа есть список стеков: выбери существующий VirtualChassis — новый свич войдёт в него участником (позиция берётся из суффикса имени «/N»).

## Перенос

Перенести устройство в другую стойку/юнит — детали → карандаш (поля «Стойка», «Юнит»), либо перетащи устройство в дереве на нужную стойку.
