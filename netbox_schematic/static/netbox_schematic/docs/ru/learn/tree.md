# Иерархия локаций и устройств

Дерево слева — карта всего: **регионы → группы площадок → площадки → серверные → стойки, щиты и устройства**. Клик по узлу загружает эту область на схему: серверная — одна комната, площадка — все её серверные, регион — всё сразу с контурами.

## Что умеет дерево

- **Клик** — загрузить область (текущая подсвечена).
- **Правый клик / долгое нажатие** — меню «Добавить»: серверную, стойку, силовой щит, фидер, устройство из палитры решений.
- **Перетаскивание**: устройство → в стойку или серверную; стойку → в другую серверную; щит → в серверную; фидер → в другой щит. Схема перерисуется сама.
- Значки подсказывают тип: стойка, щит, PDU, свич — у каждого свой.

## Сценарий: новая серверная с нуля

1. ПКМ по площадке → «Добавить» → «Серверная», назови.
2. ПКМ по серверной → «Стойка» — появится колонка на схеме.
3. Туда же — «Силовой щит», в щите — фидер.
4. Устройства — из палитры «+» на схеме или из этого же меню.

## Сценарий: устройство не в той серверной

Перетащи его в дереве на нужную серверную (или стойку). Кабели при переносе сохраняются — но на схеме связь между серверными станет «межкомнатной» и уйдёт за контур.

## Поиск и фильтр

Поиск в шапке находит устройства/стойки по имени и прыгает к ним. Фильтр ролей скрывает на схеме всё лишнее (например, показать только камеры и свичи).
