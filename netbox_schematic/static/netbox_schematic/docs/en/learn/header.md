# Page header

Left to right:

- **NetBox** (the logo) — back to NetBox itself.
- **Поиск** (search) — devices and racks by name; picking a result jumps to the object on the schema.
- **Обновить** (refresh) — re-read the data from NetBox (the plugin does not poll the server by itself — press this after edits made in another tab).
- **Импорт / Экспорт / Аудит** — working with Excel (its own topic, "Import / Export").
- **Каталог** (the device catalog) — device models; a ⚠ on the button means there are models without ports.
- **Слои** (layers) — Питание, Console, VLAN, Wi-Fi, Circuits: highlights the links of the chosen layer.
- **Фильтр ролей** (role filter) — hide the roles you don't need on the schema.
- **Физический / Беспроводной** (physical / wireless) — the port view switch.
- **✏️ Режим редактирования** (edit mode) — building things (the "Edit mode" topic).
- **Тема** (theme) — light/dark.
- **Your user name** — the profile menu.

## Bottom right

The version badge **vX.Y.Z** — this very button: «Последние изменения» (what's new) and «Обучение» (learning).

## The schema panel

Below the header the canvas has settings of its own: wire style (smooth/angular, drawn over the ports), node density, a legend of port types. They are remembered in the browser.
